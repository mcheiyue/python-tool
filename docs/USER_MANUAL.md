## 安装与启动

### 系统要求
- Windows 10/11
- 建议安装 Microsoft Office 或 LibreOffice 以获得完整的文档转换功能

### 启动应用
双击 `AI Office Tool.exe` 即可启动。无需安装，开箱即用。

## 界面概览

应用采用现代化的 Fluent Design 设计风格：

- **侧边栏导航**：左侧为功能分类导航，点击图标切换不同工具箱。
- **全局搜索**：顶部设有搜索框，输入关键字（如 "PDF"、"压缩"）可快速定位功能。
- **功能区域**：右侧主要区域显示当前选中的工具界面。
- **主题切换**：支持 浅色/深色/自动 模式，随系统自动切换。

## 功能详情

### Office 工具
提供常用办公文档的格式转换功能。

- **PPT 转 PDF**: 将 PowerPoint 演示文稿 (.pptx) 无损转换为 PDF 文档。
- **PPT 转图片**: 将每一页幻灯片导出为高清图片 (PNG/JPG)。
- **Word 转 PDF**: 将 Word 文档 (.docx) 转换为 PDF。
- **Doc 转 Docx**: 批量将旧版 .doc 格式升级为 .docx 格式。
- **Excel 转 PDF**: 将 Excel 表格转换为 PDF 格式。
- **Word ↔ Markdown**: 支持 Word 文档与 Markdown 格式的相互转换，适合文档迁移。
- **LibreOffice 格式转换**: 利用本地 LibreOffice 引擎进行高质量转换 (支持 ODT, ODS 等格式)。

### PDF 工具箱
全能的 PDF 处理中心。

- **PDF 合并**: 将多个 PDF 文件按顺序合并为一个文件。支持拖拽排序。
- **PDF 压缩**: 智能压缩 PDF 大小，提供 屏幕/电子书/打印 等多种预设配置。
- **PDF 拆分/提取**: 
    - 拆分：将 PDF 拆分为单页文件。
    - 提取：输入页码范围 (如 "1-5, 8") 提取特定页面。
- **PDF 图片提取**: 一键提取 PDF 文档中包含的所有原始图片资源。
- **PDF 页面渲染**: 将 PDF 页面渲染为高清图片，支持自定义 DPI。

### 图片工具箱
图像处理与转换工具。

- **图片取色**: 屏幕取色器或从图片中提取主色调，复制 HEX/RGB 代码。
- **PNG 转 SVG**: 将位图 (PNG/JPG) 转换为矢量图 (SVG)，适合图标处理。
- **图片格式转换**: 支持 PNG, JPG, WEBP, BMP, ICO, TIFF 等格式互转。
- **图片转 PDF**: 将多张图片合并为一个 PDF 文档，常用于扫描件整理。

### 文本工具箱
开发者与写作者的利器。

- **Markdown 转 PDF**: 将 Markdown 文档渲染为排版精美的 PDF。
- **Markdown ↔ HTML**: Markdown 与 HTML 代码互转。
- **Markdown 批量转 PDF**: 批量处理 Markdown 文件，支持数学公式渲染。
- **TXT 转 PDF**: 简单文本文件转 PDF，支持自定义字体。
- **代码提取**: 扫描项目文件夹，提取指定语言源代码并合并为一个文档（适合申请软著）。

### 实用工具
提升效率的小工具。

- **批量重命名**: 
    - 支持前缀/后缀添加。
    - 支持数字序列 (001, 002...)。
    - 支持模板变量（如 `{date}` `{original_name}`）。
    - 实时预览重命名结果。
- **剪贴板图片助手**: 
    - 自动监视剪贴板中的图片。
    - 一键保存到本地。
    - 快速查看历史记录。

## 常见问题

**Q: 转换功能提示"未检测到 LibreOffice"？**  
A: 部分高级转换功能依赖 LibreOffice。请前往 [LibreOffice 官网](https://zh-cn.libreoffice.org/) 下载并安装，程序会自动检测。

**Q: PDF 转换速度较慢？**  
A: 文件较大或图片较多时，处理时间会相应增加。如果是扫描版 PDF，压缩和渲染会消耗更多 CPU 资源。

**Q: 如何反馈 Bug？**  
A: 请访问项目 GitHub Issues 页面提交反馈。
