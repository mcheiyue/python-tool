# 项目工作流规则

本规则定义了在此项目 (`python-tool`) 中完成任务前的标准流程。

## 任务完成后检查清单

1. **确认修改结果**
   - 询问用户："本次修改是否有问题？"
   - 等待用户确认无问题后再进入下一步

2. **README 更新检查**
   - 评估本次修改是否涉及：新功能、API 变更、依赖变更、使用方式变更
   - 如涉及上述内容，给出你的建议，并询问用户："是否需要更新 README 文件？"
   - 用户同意后执行更新

3. **Git 提交**
   - 所有确认完成后，询问用户："是否提交 Git？"
   - 用户同意后，使用Git Tools MCP工具，规范的 Commit Message 格式提交
