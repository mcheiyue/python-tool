## 缓存优化详情（NEW）

### 性能提升数据
| 场景 | 编译时间 | 提升幅度 |
|------|----------|----------|
| 首次完整编译 | ~30 分钟 | 基准 |
| 增量编译（有缓存） | ~5-10 分钟 | **60%-80%** |

### 实现原理
**修改前**（删除所有内容，包括缓存）：
```batch
if exist dist\standalone rmdir /s /q dist\standalone
```

**修改后**（只删除产物，保留缓存）：
```batch
if exist dist\standalone\main.dist (
    echo [INFO] 清理旧的构建产物（保留编译缓存）...
    rmdir /s /q dist\standalone\main.dist
)
if exist dist\standalone\main.build (
    echo [INFO] 检测到编译缓存，将加速构建过程
)
```

### 缓存目录结构
```
dist/
├── standalone/
│   ├── main.build/     ← 编译缓存（保留，~500MB）
│   └── main.dist/      ← 最终产物（删除重建）
└── onefile/
    ├── main.build/     ← 编译缓存（保留，~500MB）
    └── *.exe           ← 最终产物（删除重建）
```
